# PRD：ShortFilm Agent（AIGC 内容生产平台）

> 本文根据现有代码倒推，描述的是**已实现**的产品，不是规划。版本 v0.1.0。

## 1. 产品概述

| 项 | 内容 |
| --- | --- |
| 定位 | 可复用的 AIGC 内容生产底座：一句需求 → 多阶段生成 → 人工逐步确认 → 产出视频 / 图片 |
| 核心价值 | ① 一套引擎支撑多个行业产品；② 每一步可控、可改、可重做；③ 模型可自由切换 |
| 目标用户 | 主要：学习 AIGC 产品设计的产品经理（教学用）；次要：短视频创作者、电商运营、市场人员 |
| 产品形态 | 本地运行的网页应用（单人使用，无账号体系） |

## 2. 用户场景

| 场景 | 用户 | 输入 | 输出 |
| --- | --- | --- | --- |
| AI 短片 | 创作者 | 一句故事灵感 | 多集剧情短片 |
| 电商广告片 | 电商运营 | 商品 + 卖点 + 人群 | 30–45 秒竖屏带货视频 |
| 漫剧 | 内容创作者 | 世界观 + 主角设定 | 竖屏多集漫画短剧 |
| 旅游宣传片 | 文旅市场人员 | 目的地 + 宣传重点 | 45–60 秒宣传片 |
| 商品海报 | 电商运营 | 商品 + 卖点 | 3–4 张电商海报 |

## 3. 核心流程

```
首页选场景 → 输入需求（可上传文件 / 设集数 / 选配置）
   → 逐步创作：阶段 1 生成 → 查看 / 修改 / 重做 → 确认 → 阶段 2 … → 成片
   → 或一键生成：跳过逐步确认，自动跑完
```

## 4. 功能清单

### 4.1 首页

| 功能 | 说明 |
| --- | --- |
| 场景选择 | 卡片切换 5 个场景，首页文案、输入框提示、示例随场景变化 |
| 需求输入 | 文本框输入灵感或文案 |
| 集数 / 版本数 | 设置生成几集（电商场景叫“版本数”） |
| 生成配置 | 选风格、画面比例、分辨率、模型 |
| 联网搜索 | 写剧本时可联网查资料 |
| 上传文件 | 上传参考文档（Word / PDF 等） |
| 灵感示例 | 点击示例卡片一键填入需求 |
| 逐步创作 / 一键生成 | 两种启动方式 |

### 4.2 创作工作台（6 个阶段）

| # | 阶段 | 产出 | 用户可做的操作 |
| --- | --- | --- | --- |
| 1 | 剧本生成 | 分集剧本（场次、人物、动作、台词） | 查看、修改、要求重写、续写 |
| 2 | 角色 / 场景设计 | 角色、场景、商品设定图 | 查看、重新生成、**上传真实图片替换** |
| 3 | 分镜 | 每集 → 片段 → 镜头的画面描述 | 修改分集 / 片段 / 镜头 |
| 4 | 参考图生成 | 每个镜头的画面 | 修改画面描述、重新生成、**多版本中选一张** |
| 5 | 视频生成 | 每个镜头的视频片段 | 修改描述和时长、重新生成、**多版本中选一个** |
| 6 | 后期剪辑 | 每集一个完整视频 | 查看、下载 |

通用操作：每阶段完成后暂停等待确认；可随时停止；可对某个阶段提修改意见（干预）后重新生成。

阶段状态：待开始 / 运行中 / 等待确认 / 已完成 / 已停止 / 出错。

### 4.3 其他页面

| 页面 | 功能 |
| --- | --- |
| 历史项目 | 查看、继续、删除历史项目 |
| 设置 | 填写各模型服务商的 API Key；选择每个环节的默认模型 |
| 沙盒 | 单独测试某个模型：文本、看图理解、文生图、图生图、视频 |
| 一键流水线 | 文艺短视频（图片 / 动态短片）、数字人口播、动作迁移 |

## 5. 场景差异（同一引擎的配置项）

| 配置项 | 示例：AI 短片 vs 电商广告片 |
| --- | --- |
| 阶段名称 | 剧本生成 → 广告脚本；角色设计 → 商品与模特 |
| 默认画面比例 | 16:9 → 9:16 竖屏 |
| 篇幅 | 多集 → 1 集（每集 8–14 行） |
| 提示词 | 故事叙事 → “痛点 → 卖点 → 证明 → 行动号召”结构 |
| 阶段数量 | 商品海报只有前 4 个阶段，不做视频 |

## 6. 非功能需求（现状）

| 项 | 现状 |
| --- | --- |
| 账号 / 权限 | 无，所有人都能访问所有项目 |
| 数据存储 | 本地文件，无数据库 |
| 并发 | 单机，各模型按注册表设定的并发数调用 |
| 进度反馈 | 实时进度推送 |
| 语言 | 界面中文 |
| 部署 | 本地运行或 Docker |

## 7. 不在范围内（当前未实现）

- 多用户、登录、团队协作
- 计费、额度管理
- 内容审核
- 线上部署方案（需自行处理鉴权、数据库、存储）
- 跨镜头一致性自动检查、多镜头并行生成（路线图中）

## 8. 建议的衡量指标（原项目未定义）

| 指标 | 含义 |
| --- | --- |
| 阶段通过率 | 生成后直接确认、不重做的比例，用来衡量提示词质量 |
| 平均重做次数 | 每个阶段平均重新生成几次 |
| 成片完成率 | 开始的项目中最终产出成片的比例 |
| 单片成本 / 耗时 | 一部成片的模型调用费用和总时长 |
