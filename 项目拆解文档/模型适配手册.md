# 模型适配手册

## 1. 结论

- 换模型：**设置页下拉选择**，不用改代码。
- 加同一服务商的新模型：**改一份配置**，不用改代码。
- 接入全新的服务商：**要写代码**（找开发）。
- 所有模型都按“类型”分组，每个阶段只认类型，不认具体模型。

## 2. 模型类型 ↔ 阶段

| 类型 | 用途 | 配置项（`config.yaml` → `models`） | 用在哪个阶段 |
| --- | --- | --- | --- |
| llm 文本模型 | 写剧本、拆分镜 | `llm` | ① 剧本 ③ 分镜 ④ 参考图（写画面描述） |
| vlm 视觉理解模型 | 看图、理解图片 | `vlm` | ② 角色设计 ④ 参考图 |
| t2i 文生图 | 文字 → 图片 | `image_t2i` | ② 角色设计 |
| i2i 图生图 | 参考图 + 文字 → 新图 | `image_it2i` | ④ 参考图 |
| video 视频模型 | 图片 → 视频 | `video_first_frame` / `video_start_end` / `video_reference` | ⑤ 视频 |
| —（非 AI） | 视频拼接 | 需本机安装 ffmpeg | ⑥ 后期 |

### 视频的 3 种生成模式

| 模式 | 配置值 | 说明 | 对应配置项 |
| --- | --- | --- | --- |
| 首帧生成 | `first_frame` | 用一张图作为开头生成视频（默认） | `video_first_frame` |
| 首尾帧生成 | `start_end` | 给开头和结尾两张图，生成中间过程 | `video_start_end` |
| 参考生成 | `reference` | 用角色参考图生成，适合多角色、数字人 | `video_reference` |

模式在 `generation.video_generation_mode` 或场景包的 `defaults` 里设置。

## 4. 服务商与 Key

| 服务商 | 配置位置（`api_providers.`） | 需要填的字段 | 环境变量 |
| --- | --- | --- | --- |
| 阿里百炼 | `dashscope` | api_key | `SFA_DASHSCOPE_API_KEY` |
| 火山方舟 | `ark` | api_key | `SFA_ARK_API_KEY` |
| 可灵 | `kling` | access_key + secret_key | `SFA_KLING_ACCESS_KEY` / `SFA_KLING_SECRET_KEY` |
| OpenAI | `openai` | api_key | `SFA_OPENAI_API_KEY` |
| Gemini | `gemini` | api_key | `SFA_GEMINI_API_KEY` |
| DeepSeek | `deepseek` | api_key | `SFA_DEEPSEEK_API_KEY` |
| OpenAI 兼容接口 | `openai_compatible` | api_key + base_url | `SFA_OPENAI_COMPATIBLE_*` |

需要走代理的服务商：把 `enable_proxy` 设为 true，代理地址填在 `common.proxy`。

## 6. 操作指南

### 6.1 切换模型（不用写代码）

设置页 → 模型区域 → 下拉选择 → 保存配置。立即生效。

### 6.2 新增同服务商的模型（不用写代码）

在 `backend/config.yaml` 的 `custom_models` 下添加：

```yaml
custom_models:
  qwen3.8-plus:            # 模型 id，必须和服务商官方的名字一致
    name: Qwen 3.8 Plus    # 界面上显示的名字
    provider: dashscope    # 属于哪家
    type: [llm]            # 类型：llm / vlm / t2i / i2i / video
    concurrency: 10        # 最多同时调用几次
```

图片 / 视频模型还要补充 `capabilities`（支持的比例、分辨率、时长），照抄同服务商已有模型的写法即可。保存后重启后端，或在设置页点一次保存。

### 6.3 接入私有部署 / 第三方转发的模型（不用写代码）

适用于 Ollama、vLLM、OpenRouter 等兼容 OpenAI 接口的服务，**只支持文本和视觉理解**：

```yaml
api_providers:
  openai_compatible:
    api_key: sk-xxx
    base_url: http://127.0.0.1:11434/v1
custom_models:
  qwen2.5:14b:
    name: 本地 Qwen2.5
    provider: openai_compatible
    type: [llm]
models:
  llm: qwen2.5:14b
```

### 6.4 接入全新的服务商（需要开发）

| 步骤 | 位置 |
| --- | --- |
| 1. 声明服务商和 Key 字段 | `backend/config.py` → `PROVIDERS` |
| 2. 写调用代码 | `backend/models/` 下新建客户端 |
| 3. 接入统一入口 | `backend/models/{llm,vlm,image,video}_client.py` |
| 4. 登记模型 | 注册表或 `custom_models` |
| 5. 设置页加输入框 | `frontend/app/settings/page.tsx` |

## 7. 选型注意事项

| 问题 | 结论 |
| --- | --- |
| 角色前后不一致 | 图生图要选支持“参考图”的模型（wan2.7-image、seedream） |
| 想要竖屏 | 在场景包 `defaults.video_ratio` 设为 `9:16`，并确认模型支持该比例 |
| 想省钱 / 提速 | 文本用 flash 类模型，视频用 wan2.6-i2v-flash 或 seedance fast |
| 数字人 / 多角色 | 视频模式选 `reference`，模型选 r2v 系列 |
| 生成卡住超时 | 本机测试时图片生成 300 秒超时，疑似本机代理掐断了长连接，待排查 |
